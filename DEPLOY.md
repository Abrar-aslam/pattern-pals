# Pattern Pals — GitHub Pages

This folder is the complete Pages site: one `index.html` with its CSS and JavaScript inline. The 15-minute session cap and adaptive 10-step difficulty ladder are included. The game's requested AI + frnds iframe is also retained; it loads from `ai-frnds-tracker.vercel.app`.

## Publish in the browser

The public repository is `https://github.com/Abrar-aslam/pattern-pals`.

1. Open the repository and choose **Add file → Upload files**.
2. Upload `index.html`, `.nojekyll`, and `DEPLOY.md` from this folder into the repository root.
3. Commit the upload to the `main` branch.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to finish publishing. The site address is `https://Abrar-aslam.github.io/pattern-pals/`.

GitHub Pages on a free plan requires a public repository, so the HTML source is public too. GitHub logs Pages visitor IP addresses for security. The game retains the requested AI + frnds third-party iframe, which loads from `ai-frnds-tracker.vercel.app`.

See [GitHub Pages data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) for GitHub's explanation of visitor IP logging.

## Republish after changes

For later edits, use **Add file → Upload files** to upload the changed file(s), then commit the upload to `main`.
